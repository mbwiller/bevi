# Beli map reference (added 2026-10-14)

Three screenshots of Beli's map view, the reference for Bevi's Search-tab map (TASKS.md §1c and M-16). Same rule as `../beli-screens-spec.md`: recreate the layout and behaviour, never the wordmark, icons or other users' content.

| File | What it shows |
|---|---|
| `01-been-map-web.webp` | Beli web app, Your Lists › Been as a map of Manhattan. Header "You" + avatar, "Been ▾" scope, share. Floating `List | Map` segmented control with a people button at its right; filter row `Filters 2`, `City ▾`, `Cuisine ▾`, `$, $$ ▾`. Teardrop pins coloured by score band (green ≥ 7, amber 4–6.9, red < 4) with the user's score inside; pins overlap, no clustering; blue location dot; locate button bottom-right. |
| `02-recs-map-midtown.webp` | Beli iOS, My Lists › Recs, Midtown–Gramercy zoom. "All ▾" scope; tabs Been · Want to Try · Recs · Guides · More; filter row: filter icon, `City ▾`, `Reserve`, `Order`, `Open now`, `Cuisine…`. White callout pins with a green circle holding a category icon (fork & knife, cocktail, ice cream, coffee) and the score in bold; small ↗ trending and bookmark badges on some; `View List` pill and locate button bottom-right; reservation bar "2 · Today · All Day". |
| `03-recs-map-city.webp` | Same Recs map at city zoom: callouts keep full size, still no clustering, location dot on the East River side, `View List`. |
