# Icons

Lucide 0.460.0 outline icons (ISC licence), 24×24 grid, stroke 2, inked #111111 (`text` in light mode) so they show in an image tile. In code, use the `Icon` component (or lucide-react-native in the app), which draws the same paths in `currentColor` so they follow the theme.

Gut-check faces: loved `laugh`, fine `meh`, didn't like `frown`.

Category icons: soda `cup-soda`, diet soda `candy-off`, juice `citrus`, water `glass-water`, sparkling water `droplets`, energy `zap`, coffee `coffee`, tea `leaf`, boba `milk`, sports `dumbbell`, smoothie `banana`, beer `beer`, wine `wine`, spirits & cocktails `martini`, other `globe`.
