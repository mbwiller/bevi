# Logos

The wordmark is lowercase "bevi" outlined from Fredoka Bold, with the i's dot redrawn as two bubbles. In the app, render the `Wordmark` component instead of these files.

- `wordmark.svg`: grape letters (`primary` light, #4a2a84) with `fizz` bubbles (#1494a8). For light backgrounds.
- `wordmark-dark.svg`: lavender letters (dark `primary`, #b9a4f2) with light `fizz` (#5fd6e6). For dark backgrounds.
- `wordmark-white.svg`: white letters with light `fizz` bubbles. For `tasteCard`, photos and the splash screen.
- `app-icon.svg`, `app-icon-1024.png`: white "b" and two bubbles on grape, square. iOS applies the corner mask; don't round it yourself.

Clear space around the wordmark is the height of its "e". Never recolour the bubbles, stretch it, or set "bevi" in a font to stand in for it.
