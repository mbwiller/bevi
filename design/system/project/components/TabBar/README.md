# TabBar

The five-tab bar: Feed, Your Lists, Search (a 32pt `primary` circle with a white plus, inline, labelled as Beli labels it), Leaderboard, Profile (the user's 32pt Avatar).

- Provide: `active`, `user` (for the avatar), `onChange`, `safeArea` (adds the 34pt home-indicator inset).
- Icons are 28pt outlines; labels 10pt, the active one bold.
