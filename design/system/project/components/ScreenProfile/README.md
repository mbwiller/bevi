# ScreenProfile

Profile tab (ref 02, 03): name Header with the Settings menu, Avatar 100, handle, the counts row (Bev'd · Followers · Following), Edit profile and Share profile as two equal Buttons, two StatCards (Rank on Bevi, Current streak), two ProfileListRows (Want to Try, Recommended for you), Activity · Taste Profile tabs, then your FeedPosts. The Taste Profile tab swaps the posts for a TasteProfile: the read-out over the category bars.

- Each thing is said once: the rank lives in its StatCard, not in the counts row as well, and the Bev'd count opens the Bev'd list, so there is no Bev'd row repeating the number.
- Two buttons fill the row. Settings is the menu in the Header; there is no third button for it.
- Another person's profile keeps the same order, with Follow where your own has Edit profile.
